操作说明

移动：拖动 / WASD / 方向键
射击：自动连射；长按蓄力时主炮停射，僚机前聚变阵（彩京风）
蓄力超射：按住 空格 / Shift / J，蓄满松手释放
炸弹：B / K 或触屏「炸弹」· 清弹+伤害
暂停：Esc / P
拾取： P火力（满5级后溢出→移速/射速/磁吸/炸弹/护盾）· B炸弹 · 僚僚机（默认无，吃到才有）

键盘 / 触屏操作

● 移动：拖动屏幕 / WASD / 方向键
● 射击：自动（无需按键）
● 蓄力：长按空格/Shift/J，僚机前聚；32%/62%/满蓄对应 Lv1/2/3，松手释放
● 炸弹：B / K 或右下「炸弹」按钮 — 清屏弹幕并造成伤害
● 拾取发光道具： P火力（满级溢出强化）· B炸弹 · 僚僚机
● 僚机：开局没有；吃「僚」才出现。僚机被弹/体撞击会单独消失，可用「僚」补回
