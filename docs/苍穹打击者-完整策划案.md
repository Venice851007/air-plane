## 1. 产品概述

### 1.1 一句话介绍
一款可在手机浏览器即开即玩的竖版射击游戏：选机体、打 15 关、打 Boss、吃道具强化，通关后进入更高轮回；带周榜 / 月榜。

### 1.2 目标用户
- 喜欢雷电 / 彩京风 STG、通勤碎片时间想打一局的玩家
- 站群 / 工具站导流用户（站点导航互链）
- 轻度竞技：刷周榜、月榜分数

### 1.3 核心体验循环
```
选机体 → 出击 → 清杂兵 → 精英+小兵 → 中型威胁 → 加压波 → Boss
  → 下一关（×15）→ 轮回+1 难度软递增 → 阵亡可复活 / 上传排行榜
```

### 1.4 设计支柱
1. **可读弹幕**：加压但留走廊，轮回有软封顶，避免「糊屏必死」。
2. **机体有差异**：四种机体普攻 / 超射 / 僚机手感明显不同。
3. **关卡有个性**：15 关主题递进（侦察→蜂群→装甲→狙击→混战），每关独立小兵 / 精英 / 中型 / Boss。
4. **空场零容忍**：波次调度不跳过 Boss；中型死后立刻补刷；精英必带小兵。
5. **轻竞技**：周榜每周一清、月榜每月 1 日清（北京时间）。

## 2. 玩法系统

### 2.1 基础规则
| 项 | 数值 / 规则 |
|----|-------------|
| 初始残机 | 3 |
| 本局广告复活 | 最多 3 次（演示占位） |
| 火力等级 P | 1–5；满级后溢出强化（移速 / 射速 / 磁吸 / 炸弹 / 护盾等） |
| 炸弹 | 机体初始存量不同；清屏弹 + 范围伤 |
| 僚机 | 开局 **0**；吃「僚」出现；被弹/体撞可单独损毁；可用「僚」补回 |
| 僚机软上限 | 14（性能与可读性） |
| 延长残机分数线 | 50,000 / 150,000 / 300,000 / 500,000 |
| 关卡 | 15 关 / 轮回；通关后 `cycle++`，难度软递增 |

### 2.2 操作

**触屏**
- 拖动：移动
- 自动连射（蓄力中暂停普攻）
- 右侧「蓄力」：按住蓄力，松手超射
- 右侧「炸弹」
- 左侧「暂停」

**键盘**
| 操作 | 按键 |
|------|------|
| 移动 | WASD / 方向键 |
| 蓄力超射 | 空格 / Shift / J（按住蓄满松手） |
| 炸弹 | B / K |
| 暂停 | Esc / P |

### 2.3 战斗资源
- **分数**：击破、奖牌、关卡 / Boss 奖励；轮回有分数加成。
- **火力 P**：拾取提升弹幕密度与强度。
- **炸弹**：应急解围。
- **僚机**：侧翼火力；满蓄时可参与机体特色齐射。
- **护盾 / 溢出强化**：P 满后继续吃 P 的收益转化。

### 2.4 阵亡与复活
1. 中弹扣残机，掉落部分火力，短暂无敌。
2. 残机归零 → 结算界面。
3. 若本局复活次数未用尽：可点「看广告复活」（演示倒计时，非真实广告）。
4. 复活后残机 1、短暂无敌，可继续当前关。
5. 结算可上传昵称分数至 **周榜 + 月榜**。

## 3. 机体设定（4 选 1）

| 机体 | 定位 | 移速 | 射速间隔 | 初始炸弹 | 普攻 | 超射（满蓄松手） | 僚机 |
|------|------|------|----------|----------|------|------------------|------|
| **迅雷号** | 均衡集中 | 340 | 0.14s | 3 | 正前方集中 | 追迹导弹雨，优先近敌 | 前方轻弹；满蓄扇形追迹 |
| **凤凰羽** | 高速广角 | 400 | 0.16s | 2 | 扇形散射 | 烈焰子母弹下砸爆炸 | 宽轨侧射；满蓄火焰子母 |
| **铁卫舰** | 重甲低速 | 260 | 0.18s | 3 | 三连光束 | 铁壁屏障：清近弹+无敌+穿甲束；蓄力大幅减速 | 单僚强射；满蓄护盾脉冲 |
| **影刃** | 极速双管 | 440 | 0.11s | 2 | 窄道连射 | 短时贯穿激光 | 贴身细束；满蓄穿甲穿透 |

**设计意图**
- 迅雷：新手默认、稳定输出。
- 凤凰：机动换清屏，炸弹少需走位。
- 铁卫：抗压与超射无敌窗，蓄力有移速惩罚。
- 影刃：高风险高射速，吃操作。

## 4. 敌人与波次规范

### 4.1 敌人阶层
| 阶层 | 角色 | 规则 |
|------|------|------|
| 小兵（fodder / aimed） | 铺场、制造走位压力 | 每关开场与加压波必有 |
| 精英 | 厚血、特色弹幕 | **出场必须伴随小兵护航**（代码层强制） |
| 中型威胁（mid） | 关卡中段 Bosslet，2 阶段 | 每关 1 次；击破后立即调度后续波 / Boss |
| 关底 Boss | 主题弹幕，3–4 阶段 | 每关 1 次；第 15 关终焉加强 |

### 4.2 兵种族
- **侦察 scout**：Z 字 / 横排小兵、瞄准机、侦察精英  
- **蜂群 drone**：蜂群 / V 字、散射机、蜂群精英  
- **装甲 tank**：重甲精英、环射装甲  
- **狙击 sniper**：滞空狙、激光精英、炮台  

### 4.3 波次调度铁律（防空场）
1. 时间轴推进波次；**中型 / Boss 存活时不得跳过后续 mid/boss 波**。  
2. 中型死后立刻 `flushWaves()`，该出 Boss 马上出。  
3. 兜底：波次耗尽、场清空、中型已打完却未出 Boss → 强制刷 Boss。  
4. 精英生成函数内自动附带小兵，避免「光杆精英」。

### 4.4 难度曲线
- **关内**：小兵 → 精英+小兵 → 中型 → 混编加压 → Boss。  
- **关间**：1–3 侦察教学 → 4–6 密度 → 7–9 装甲抗性 → 10–12 狙击威胁 → 13–15 全面混战。  
- **轮回**：HP / 分数 / 刷怪量软递增并封顶，弹幕更密但保留走廊。  
- `spawnN`：基础数量 + 关卡加成 + 轮回加成（软封顶）。

## 5. 十五关详细表

每关结构统一：**开场小兵 → 精英带小兵 → 中型 → 加压（精英+小兵）→ Boss**。

| 关 | 名称 | 主题 | Boss 原型 | 关卡感受 |
|----|------|------|-----------|----------|
| 1 | 沿海空域 | 侦察 scout | 环咒 ring | 教学：走位与集中火力 |
| 2 | 港湾巡逻 | 侦察 scout | 狙击 sniper | 引入瞄准弹、预判走位 |
| 3 | 近海突袭 | 侦察 scout | 装甲 tank | 侦察线收束，抗压预演 |
| 4 | 蜂群峡谷 | 蜂群 drone | 虫群 swarm | 高密度小单位 |
| 5 | 虫潮裂谷 | 蜂群 drone | 激光 laser | 蜂群 + 激光轴线 |
| 6 | 千机风暴 | 蜂群 drone | 疾影 dasher | 高速单位、侧向压迫 |
| 7 | 装甲高地 | 装甲 tank | 环咒 ring | 厚血敌人，强调炸弹/超射 |
| 8 | 铁壁防线 | 装甲 tank | 装甲 tank | 装甲对撞，护航小兵 |
| 9 | 重装要塞 | 装甲 tank | 狙击 sniper | 装甲+狙击混编 |
| 10 | 狙击云层 | 狙击 sniper | 激光 laser | 滞空狙与炮台 |
| 11 | 天狙走廊 | 狙击 sniper | 虫群 swarm | 走廊走位 + 虫群干扰 |
| 12 | 轨道猎场 | 狙击 sniper | 疾影 dasher | 狙+装甲+疾影 |
| 13 | 混沌前线 | 混战 mix | 激光 laser | 全兵种混编开打 |
| 14 | 裂空决战 | 混战 mix | 疾影 dasher | 高压混战 |
| 15 | 终焉苍穹 | 混战 mix | 终焉 finale | 4 阶段终焉 Boss，HP 额外加强 |

每关统一结构：**开场小兵 → 精英（必带小兵）→ 中型威胁 → 混编加压 → 关底 Boss**。

中型 / Boss 显示名随原型变化，例如：环咒使徒→环咒法师、狙杀哨站→天狙炮台、装甲壁垒→铁壁巨像、蜂群节点→千机母舰、镜影哨舰→镜光扫射舰、疾影斥候→疾影突击者；第 15 关 Boss 固定为 **终焉·苍穹审判**。


### 5.1 Boss 原型弹幕设计要点
| 原型 | 关键词 | 玩家对策 |
|------|--------|----------|
| ring 环咒 | 环形弹，留放射状空隙 | 钻空隙、别贴边 |
| sniper 天狙 | 蓄力激光 / 点名弹 | 看提示走位 |
| tank 铁壁 | 慢速厚血、重弹 | 炸弹窗口、超射爆发 |
| swarm 千机 | 母舰洒弹 + 护航 | 优先清护航再打本体 |
| laser 镜光 | 扫射带 | 预判条带间隙 |
| dasher 疾影 | 侧冲、突发 | 保持中轴灵活 |
| finale 终焉 | 多阶段混合 | 保存炸弹与超射过阶段转换 |

### 5.2 中型 / Boss 数值框架（现网）
- 中型 HP ≈ `(90 + stage×45) × midHpMult × 轮回系数`，2 阶段。  
- Boss HP ≈ `(200 + stage×90) × bossHpMult × 轮回系数`；第 15 关再 ×1.2。  
- Boss 阶段：常规 3 段；终焉 / 第 15 关 4 段。

## 7. 关卡与轮回流程

```
标题 → 选机体 →（可选出击须知）→ 第 1 关
  … 第 15 关 Boss 击破
→ 轮回结算加成 → 第 2 轮回第 1 关（难度↑）
→ 可无限轮回，直到残机耗尽
```

- 通关一轮回：分数奖励，展示横幅后进入下一轮回第 1 关。  
- 暂停：继续 / 重开选机体 / 回标题。

## 8. 排行榜

| 榜 | 周期（北京时间 Asia/Shanghai） | 规则 |
|----|--------------------------------|------|
| 周榜 | 每周一换新 key | 全局 Top（约 50）；同昵称保留最高分 |
| 月榜 | 每月 1 日换新 key | 同上 |

- 入口：标题页「周榜 / 月榜」；结算页可提交昵称。  
- 昵称：1–8 字（中英文数字与 `_` `-`）。  
- 提交字段：昵称、分数、关卡、轮回、机体名。  
- 防刷：按 IP 短时限流。  
- 后端：Cloudflare Worker + KV（`air-plane` / `RANKS`）。
